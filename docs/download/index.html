Get Orca

Free and open source. Install it, start it, and Orca sets up the rest: a container runtime, its VM where your platform needs one, and the gateway.

macOS

Apple Silicon. Orca installs Lima and runs Docker in a lightweight Linux VM; no Docker Desktop needed.

Download .dmg21 MB
Your platform

Windows

64-bit installer. Orca runs Docker inside WSL2 and sets it up on first start.

Download installer15 MB
Your platform

Linux

x86-64. Talks to Docker or Podman directly. The AppImage updates itself.

AppImage101 MB.deb24 MB
Your platform

On a server

Run the Orca daemon on a Debian or Ubuntu server and manage it from the desktop app, next to your own machine.

Terminal
curl -fsSL https://orca-desktop.com/install-daemon.sh | sudo sh
Remote hosts guide

After installing

  1. Start Orca. The first start checks your system and offers to install anything missing.
  2. Open a project. Anything you start with docker compose up shows up as a stack.
  3. Give it a hostname. Start the gateway and open https://<name>.localhost.
Follow the quickstart
