Everything you need

Containers, images, compose stacks, Kubernetes, AI, and more — all in one app.

Container Management

Full lifecycle with live CPU/memory sparklines, interactive terminal, log viewer with search, container diagnostics, and export as docker-compose.yml.

Images & Registry

Pull with Docker Hub search, build from Dockerfile, browse image files, prune unused, and authenticate with private registries (Docker Hub, GitHub, GitLab, ECR).

Compose Stacks

Auto-detects compose projects from container labels. Compose up/down/pull with full streaming output. Service health indicators at a glance.

Kubernetes

One-click k3s cluster with Traefik ingress. Manage pods, deployments, services, ingresses, PVCs. Scale, restart, apply YAML manifests, view pod logs.

AI Assistant

Built-in chat with Claude, GPT, or Gemini. One-click container diagnostics. Context-aware — click the AI button on any container to ask about it with logs pre-loaded.

Agent APIs

MCP server for Claude Code/Desktop, OpenAI-compatible function calling endpoint, and direct tool execution. 27 tools across 8 categories.

Volumes & Networks

Create, inspect, and delete volumes with built-in file browser. Manage networks with subnet/gateway configuration. Full Docker resource management.

App Templates

One-click deploy for PostgreSQL, Redis, Nginx, Grafana, Ollama, OpenClaw, and more. Create your own templates. Structured editors for ports, env vars, volumes.

Guided Setup

Setup wizard for new users with real-time streaming progress. One-click Docker install on Linux and Windows (WSL2). Auto-detects existing installations.

Built for AI agents

Orca Desktop exposes a full container management API that any AI agent can use. Connect Claude Code, OpenAI agents, or any MCP-compatible client.

  • MCP server with 27 tools
  • OpenAI-compatible function calling
  • Direct tool execution endpoint
  • Bearer token authentication
// Add to your MCP config { "mcpServers": { "orca": { "url": "http://127.0.0.1:9477/api/v1/agent/mcp", "headers": { "Authorization": "Bearer YOUR_TOKEN" } } } }

Cross-platform, native performance

Built with Rust and Tauri for minimal resource usage. No Electron. Runs natively on all platforms with platform-specific container runtime integration.

  • Linux — native Docker/Podman, no VM needed
  • macOS — Lima VM with Apple Virtualization
  • Windows — WSL2 with Docker
  • Signed auto-updates with one-click install
