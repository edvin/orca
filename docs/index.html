Orca Desktop

Open source Docker Desktop alternative with built-in AI. Manage containers, images, compose stacks, and Kubernetes.

Download View on GitHub

Everything you need

Containers, images, compose stacks, Kubernetes, AI — all in one place.

📦

Container Management

Full lifecycle management with live CPU/memory sparklines, exec terminal, log viewer with search, and one-click diagnostics for failed containers.

🖼️

Image Management

Pull with Docker Hub search autocomplete, build from Dockerfile, batch delete, prune unused images, and authenticate with private registries.

📋

Compose Stacks

Auto-detects compose projects from container labels. Run compose up/down/pull with full output. Service health dots at a glance.

☸️

Kubernetes

One-click k3s cluster with Traefik ingress. Manage pods, deployments, services, PVCs. Scale, restart, apply YAML manifests.

🤖

AI Assistant

Built-in chat powered by Claude or GPT. One-click crash diagnosis with pre-filled context. Actionable fix suggestions.

🔌

Agent APIs

MCP server for Claude Code, OpenAI-compatible function calling, and direct tool execution. 27 tools across 8 categories.

🚀

App Templates

One-click deployable apps — databases, web servers, AI tools, monitoring, and more. Create your own templates with structured port/env/volume editors.

✨

Guided Setup

Welcome wizard guides new users through runtime installation. Progress dialogs show step-by-step output. Works on Linux, macOS, and Windows.

🔒

Security

Mandatory API token authentication with constant-time comparison. Unix socket mode. Network exposure warnings. Signed auto-updates.
