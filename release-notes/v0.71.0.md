## A network map

- **See how containers connect:** **Map** on the **Networks** page shows each network in use as a card with its containers, their full names and IP addresses. **List** is still there, and Orca remembers which you used last.
- **Containers on several networks** have a dashed outline and a dot in the colour of each other network they're on.
- **Hover to trace:** point at a container to draw a link to each of its other networks; point at a network to see every container it shares with others. Everything else fades.
- **Click a container** to open its page.
- **Less clutter:** networks with no containers, such as `host` and `none`, are listed below the map instead of taking up cards.
