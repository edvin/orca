## A new look, and pages that say more

- **A fresh design:** a new typeface, panels with depth, tabs as segmented controls, and a calmer main button. Every page gets it.
- **Container page:** where the container sits (stack, image, ports, networks, gateway address), live CPU, memory, network and disk as instruments, the last health checks as a bar, and its restart policy, gateway and limits a click away. The image reads as its short name and links to the Images page.
- **Volumes say what they're for:** each volume shows the container that mounts it and the path, so anonymous volumes are no longer just long IDs. Filter on unused ones and see how much space they take. A volume's page lists the containers that use it.
- **Networks:** a card per network with the containers on it, its kind and addresses, in the same colours as the map.
- **Builds:** one card per image with its latest run and a bar per run, instead of a long table. Builds from `docker build` and compose now open with their logs, rather than an error.
- **Dialogs:** wider, with fields side by side, dropdowns that fill their field, and choices explained. Create network no longer offers the `host` and `none` drivers Docker refuses.
- **Gateway:** a hostname with both a plain and a WebSocket route shows once, and a route a workspace file lists twice is added once.
